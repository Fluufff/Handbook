# Fluufff IT Technical Documentation

This repository houses the markdown based documentation for Fluufff IT.

It can be read either right here at [docs/](docs/), or at [docs.fluufff.org](https://docs.fluufff.org).

## Local dev

```shell
# The vscode devcontainers do these for you
python -m venv .venv
pip install -r requirements.txt

mkdocs serve
```
